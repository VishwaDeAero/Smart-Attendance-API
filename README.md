## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** JavaScript
- **Package Manager:** Npm

### Installation

Build Smart-Attendance-API from the source and intsall dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/VishwaDeAero/Smart-Attendance-API
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd Smart-Attendance-API
    ```

3. **Install the dependencies:**

	<!-- [![npm][npm-shield]][npm-link] -->


### Usage

Run the project with:

**Using [npm](https://www.npmjs.com/):**
```sh
npm start
```

### Testing

Smart-attendance-api uses the {__test_framework__} test framework. Run the test suite with:

**Using [npm](https://www.npmjs.com/):**
```sh
npm test
```
